# Components

The interface is built from one set of Svelte 5 components, not a template per screen. [#50](https://github.com/BradHudsonGrant/RESONANCE/issues/50) builds the primitives, [#51](https://github.com/BradHudsonGrant/RESONANCE/issues/51) the shell, and [#52](https://github.com/BradHudsonGrant/RESONANCE/issues/52) the Library and Mix views. Later milestones feed real data into the same components.

## Layers

```
0  Tokens       ui/src/lib/design/tokens.css
1  Primitives   ui/src/lib/design/*.svelte
2  Composed     ui/src/lib/wave/, ui/src/lib/library/, ui/src/lib/mix/
3  Regions      ui/src/lib/shell/, ui/src/lib/library/Inspector.svelte
4  Screens      ui/src/App.svelte, Library.svelte, Mix.svelte, DesignPage.svelte
```

Each layer builds only on the layers before it.

## Rules

1. One component per concept. Placements differ by typed props (`size`, `variant`, `mode`, `active`), never by copied markup or styles. `Deck` is both the card in the dock and the full deck in Mix, and `Waveform` draws every waveform.
2. No raw values in a component. Every size, gap, radius, colour, font, font size and duration comes from a token in `tokens.css`. A measurement from the boards sets a token once and is never copied into component CSS.
3. Names from the domain. A component is a PascalCase file named after what it is (`Deck`, `Waveform`, `Inspector`, `TrackTable`). A supporting module is a lowercase domain noun (`clock.ts`, `frames.ts`, `columns.ts`). Never `utils`, `helpers`, `manager` or `service`.

## Where files go

[architecture.md](../architecture.md#repository-layout) sketches the UI folders as `design/`, `components/`, `spaces/` and `ipc/`. The code keeps each domain in one folder instead, with its views, components, state and tests together:

```
ui/src/
  App.svelte       the shell grid
  design-page/     /design.html, every primitive in both themes
  lib/design/      tokens.css, base.css, the primitives and the logo SVGs
  lib/wave/        the dot wave
  lib/shell/       TopBar, Sidebar, CommandBar, TransitionDock, PlayerBar
  lib/library/     Library, TrackTable, Inspector, ScanFolder and their state
  lib/mix/         Mix, Deck, Waveform, the renderer, clock and frames
  lib/ipc/         the generated bindings and the transport client
```

`Sidebar.svelte` replaces `Rail.svelte` in #51. A new space gets its own folder when its milestone starts: `lib/prep/` (M3), `lib/replay/` (M9) and `lib/sets/` (M10).
